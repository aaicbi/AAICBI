# AAICBI brand artwork

**Current: `v3/`** — the Nested Ascent mark in the platform's own colours, Manrope ExtraBold wordmark, with the mark above the word inside one equilateral triangle. Open `v3/logo-sheet.html`. Regenerate everything with `python3 docs/brand/v3/build_logo.py` (needs `fonttools` and the Manrope woff files from the `@fontsource/manrope` npm package), then `python3 docs/brand/v3/build_sheet.py` and `node scripts/brand-icons.cjs` for the PNG app icons.

Superseded (kept for history): `brand-guide.html` and `svg/` (version 1, navy and amber palette) and `v2/` (wordmark-only directions). The app uses `src/components/Logo.tsx` and `public/logo.svg`; the outlined letters in `src/components/brand/wordmark.ts` are generated by `v3/build_logo.py`.
